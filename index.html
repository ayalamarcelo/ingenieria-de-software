Sistema de Préstamo de Bicicletas – BiciYa (Tema 2)

BiciYa es un servicio de préstamo de bicicletas públicas que opera en varias ciudades del país. Los usuarios pueden tomar una bicicleta desde cualquier estación habilitada y devolverla en otra distinta. Para utilizar el servicio, los usuarios deben estar registrados y contar con una tarjeta digital activa.

Desde la app, el usuario puede consultar estaciones con bicicletas disponibles. Para comenzar el viaje, debe acercarse a una estación, escanear el código QR para reclamar la bicicleta y reservarla por hasta 10 minutos. Una vez retirada, el sistema registra el trayecto y el tiempo de uso. Al finalizar el viaje, el usuario debe escanear el QR de la estación donde vuelve la bicicleta para completar correctamente la operación.

Luego, el sistema calcula si corresponde aplicar un recargo (por tiempo extra o devolución en estación no habilitada). El usuario recibe una notificación con el resumen del viaje. El sistema no permite controlar el estado y mantenimiento de las bicicletas prestadas, como tampoco las cuestiones referidas al tránsito. Cada mes, el sistema generará un informe con tiempos promedios de alquiler, cantidad de bicis alquiladas, etc., para poder iterar el funcionamiento del sistema.
